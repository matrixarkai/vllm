# Community conduct

Everyone is welcome to participate. Be respectful, provide constructive technical
feedback, credit others, and respect privacy. Harassment, discrimination, threats,
and publication of private credentials or personal information are not acceptable.

Maintainers may moderate harmful content and restrict abusive participation.
For a public moderation concern, contact maintainers through this fork's GitHub
issues without publishing sensitive personal details. Use GitHub's private abuse
reporting channels when a public report would expose someone to harm.

Security vulnerabilities follow [the security policy](SECURITY.md), not public
issue disclosure.
